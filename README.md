# Vectron Audio Assets CDN

Official royalty-free acoustic assets, UI sound effects, and ambient beds for the [Vectron Motion Graphics Engine](https://github.com/Gaurav-Wankhede).

## Purpose
This repository serves as the official high-availability CDN mirror for Vectron projects. Whenever a user builds or renders a scene with sound design requirements, the Vectron CLI automatically resolves and hydrates the needed  files on demand.

## Distribution Architecture
- **jsDelivr Global CDN**:
  `https://cdn.jsdelivr.net/gh/Gaurav-Wankhede/vectron-audio-assets@v1.0.0/ui/{file.wav}`
- **GitHub Direct Releases**:
  `https://github.com/Gaurav-Wankhede/vectron-audio-assets/releases/download/v1.0.0/{file.wav}`
